# Task: 后端JWT认证服务实现

## Description
在NestJS后端实现完整的JWT认证服务，包括用户登录验证、JWT Token生成和验证、用户信息查询服务。建立认证中间件和守卫，为API接口提供安全的身份验证机制。

## Acceptance Criteria
- [ ] 实现AuthModule模块，配置JWT策略和认证服务
- [ ] 创建AuthService，提供login、validateUser、generateTokens方法
- [ ] 实现UserService，提供用户查询和验证功能
- [ ] 创建JwtAuthGuard，保护需要认证的API接口
- [ ] 实现JWT Token刷新机制，支持Access/Refresh Token双Token模式
- [ ] 配置bcrypt密码加密和验证
- [ ] 创建登录API接口 POST /auth/login
- [ ] 创建用户信息查询接口 GET /auth/profile
- [ ] 实现Token刷新接口 POST /auth/refresh

## Technical Details
- **核心文件**: `backend/src/auth/auth.module.ts`, `auth.service.ts`, `auth.controller.ts`
- **JWT配置**: 使用@nestjs/jwt包，配置密钥和过期时间
- **密码加密**: 使用bcryptjs进行密码哈希和验证
- **环境变量**: JWT_SECRET、JWT_ACCESS_EXPIRES、JWT_REFRESH_EXPIRES
- **数据库集成**: 与User实体集成，查询用户信息和验证凭据
- **错误处理**: 统一异常处理，返回安全的错误信息
