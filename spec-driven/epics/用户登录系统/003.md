# Task: 前端登录系统实现

## Description
在frontend-app中实现完整的用户登录系统，包括登录页面、表单组件、认证状态管理和API集成。使用Next.js 15 App Router、shadcn/ui组件库和Tailwind CSS v4构建现代化的登录界面和用户体验。

## Acceptance Criteria
- [ ] 创建登录页面 `/app/login/page.tsx`，响应式设计适配多种设备
- [ ] 实现LoginForm组件，集成shadcn/ui的Form和Input组件
- [ ] 添加表单验证，邮箱格式验证和密码强度检查
- [ ] 实现AuthProvider Context，管理全局认证状态
- [ ] 创建useAuth Hook，提供登录、登出、状态查询功能
- [ ] 集成后端登录API，处理登录成功/失败逻辑
- [ ] 实现JWT Token存储和自动刷新机制
- [ ] 添加加载状态、错误处理和成功反馈
- [ ] 实现登录后重定向到dashboard首页

## Technical Details
- **页面路径**: `frontend-app/app/login/page.tsx`
- **组件文件**: `components/auth/LoginForm.tsx`, `components/auth/AuthProvider.tsx`
- **状态管理**: React Context + useReducer模式
- **表单验证**: 使用zod schema validation
- **Token存储**: HttpOnly Cookie (由后端设置)
- **API调用**: 使用fetch或axios调用认证API
- **错误处理**: toast通知显示错误信息
- **样式规范**: 严格使用Tailwind v4语法，避免v3语法
