# Task: 共享类型定义和数据库设计

## Description
在shared包中定义用户认证系统的TypeScript类型，包括用户信息、JWT Token、角色权限等核心数据结构。同时设计数据库用户表结构，为后续开发提供类型安全和数据模型基础。

## Acceptance Criteria
- [ ] 在shared包中创建认证相关的TypeScript类型定义文件
- [ ] 定义User类型，包含id、email、name、role、status等字段
- [ ] 定义AuthToken类型，包含accessToken、refreshToken、expiresIn等字段
- [ ] 定义Permission和Role类型，支持基于角色的权限控制
- [ ] 定义API请求/响应类型，包含LoginRequest、LoginResponse等
- [ ] 设计数据库用户表结构，包含必要的索引和约束
- [ ] 构建shared包确保类型导出正常

## Technical Details
- **文件位置**: `shared/src/types/auth.ts`, `shared/src/types/user.ts`
- **数据库表设计**: users表，包含密码哈希、角色、创建时间、最后登录时间等
- **类型导出**: 确保前端和后端都能正确导入使用
- **角色系统**: user、premium、admin三级角色定义
- **密码安全**: 明确密码字段不在客户端类型中暴露
