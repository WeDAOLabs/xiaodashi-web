# Task: 权限控制系统实现

## Description
实现完整的基于角色的访问控制(RBAC)系统，包括前端路由保护、组件级权限控制和后端API权限验证。支持user、premium、admin三级用户角色，确保不同用户只能访问授权的功能模块。

## Acceptance Criteria
- [ ] 后端实现RolesGuard，基于JWT中的用户角色进行API权限验证
- [ ] 创建@Roles装饰器，简化API接口权限配置
- [ ] 前端实现AuthGuard组件，保护需要认证的页面路由
- [ ] 创建PermissionGate组件，基于用户角色显示/隐藏UI元素
- [ ] 实现usePermission Hook，提供权限查询功能
- [ ] 配置路由中间件，未认证用户自动重定向到登录页
- [ ] 权限不足时显示友好的错误提示页面
- [ ] 实现动态菜单，根据用户角色显示可访问的功能模块
- [ ] 支持实时权限变更，用户角色更新后立即生效

## Technical Details
- **后端文件**: `backend/src/common/guards/roles.guard.ts`, `decorators/roles.decorator.ts`
- **前端组件**: `components/auth/AuthGuard.tsx`, `components/auth/PermissionGate.tsx`
- **权限配置**: 定义角色权限映射表，支持细粒度权限控制
- **路由保护**: Next.js middleware实现页面级权限检查
- **错误处理**: 权限不足返回403状态码，前端显示友好提示
- **用户体验**: 无权限功能灰显或隐藏，避免用户困惑
- **性能优化**: 权限信息缓存，减少重复查询
