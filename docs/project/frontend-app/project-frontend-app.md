# 项目前端应用(frontend-app) 开发文档

## 项目结构
- 目录：`frontend-app`
- 项目名称：智赢 AI 营销平台

## 项目约束
- 项目使用 Tailwind CSS v4 构建，请遵循 Tailwind CSS v4 的规范。
- 项目使用 shadcn/ui 组件库，请遵循 shadcn/ui 的规范。
- 项目使用 React 19 构建，请遵循 React 19 的规范。
- 项目使用 TypeScript 构建，请遵循 TypeScript 的规范。
- 项目使用 Next.js 构建，请遵循 Next.js 的规范。
- 项目使用 ESLint 进行代码规范检查，请遵循 ESLint 的规范。
- 项目是web端项目，不用考虑移动端适配。
